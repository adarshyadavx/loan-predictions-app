# FinAI - Loan Approval Prediction using Decision Tree Classifier

This repository implements a complete, modular, and production-ready machine learning pipeline for **Loan Approval Prediction**. The pipeline handles outliers, performs feature engineering, trains a tuned **Decision Tree Classifier**, and deploys a clean **Streamlit web application** for real-time predictions.

---

## 📁 Project Structure

```
loan_prediction/

└── README.md                # Project documentation and guide
```

## ⚙️ Core Pipeline Components

### 1. Data Generation & Exploration
*   **Dataset Properties**: Contains 1000 rows and 5 columns (`Age`, `Income`, `LoanAmount`, `CreditScore`, `Approved`).
*   **Outlier Modeling**: Age contains outliers representing `Age = 144`. Income features extreme outliers representing high-net-worth values ($1M+).
*   **Class Imbalance**: Implements a sigmoid-based risk calculation thresholded to achieve a **~22% positive approval class rate** to represent real loan portfolio distributions.
*   **Exploration**: Conducted via [data_exploration.ipynb](file:///file:///Users/adarshyadav/Documents/loan_prediction/data_exploration.ipynb).

### 2. Robust Preprocessing ([preprocessing.py](file:///Users/adarshyadav/Documents/loan_prediction/preprocessing.py))
To avoid training leakages, preprocessing is implemented using Scikit-Learn custom transformers:
*   `OutlierHandler`: Caps `Age > 100` to a maximum age of 80. Income is capped at the 99th percentile, computed only on the training split and applied to test/inference sets.
*   `FeatureEngineer`: Dynamically creates `DebtToIncomeRatio` = `LoanAmount` / `Income`.
*   `StandardScaler`: Normalizes numerical values to optimize decision boundaries and distance structures.

### 3. Training & Hyperparameter Tuning ([train_model.py](file:///Users/adarshyadav/Documents/loan_prediction/train_model.py))
*   **Data Split**: 80/20 train/test split, stratified on the target `Approved`.
*   **Grid Search**: Uses 5-fold cross-validation optimizing for F1-score to handle class imbalance. Tuned parameters: `max_depth`, `min_samples_split`, `criterion`, and class weights.
*   **Pipeline Serialization**: Bundles preprocessing steps and the model into `loan_model.pkl` to guarantee seamless model serving.

### 4. Deployment Dashboard ([deploy_app.py](file:///Users/adarshyadav/Documents/loan_prediction/deploy_app.py))
A Streamlit web app allowing users to input applicant characteristics and view dynamic predictions and approval probabilities.

## 🚀 How to Run the Project

### 1. Set Up Environment & Install Dependencies
Make sure you have python installed, then install the package requirements:
```bash
pip install -r requirements.txt
```

### 2. Generate Synthetic Dataset
```bash
python3 generate_data.py
```

### 3. Run Exploratory Data Analysis
Open Jupyter notebook to view [data_exploration.ipynb](file:///Users/adarshyadav/Documents/loan_prediction/data_exploration.ipynb).

### 4. Train the Model
```bash
python3 train_model.py
```
This trains the best Decision Tree model pipeline and outputs `loan_model.pkl`.

### 5. Run the Streamlit Web Application
```bash
streamlit run deploy_app.py
```
Open the local URL generated (usually `http://localhost:8501`) in your browser to interact with the application.
